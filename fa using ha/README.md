# Full Adder Using Half Adders

## Description

A Full Adder is a combinational digital circuit that adds three 1-bit binary inputs: A, B, and Carry Input (Cin).

It produces two outputs:
- **Sum** – The sum of the three input bits.
- **Carry** – The carry output generated by the addition.

This project implements a Full Adder using two Half Adders and an OR gate, using Verilog HDL.

## Logic Equations

### Sum

```text
Sum = A ^ B ^ Cin
```

### Carry

```text
Carry = (A & B) | ((A ^ B) & Cin)
```

## Simulation

The design was simulated using Icarus Verilog with a testbench that checks all eight possible input combinations.

The simulation outputs were verified against the expected Full Adder truth table. A VCD waveform file was generated and can be viewed using GTKWave to observe the input and output signal transitions.

### Run the Simulation

**1. Compile the Verilog code**

```bash
iverilog -o fa_sim fa_using_ha.v
```

**2. Run the simulation**

```bash
vvp fa_sim
```

**3. View the waveforms**

```bash
gtkwave fa_using_ha.vcd
```
